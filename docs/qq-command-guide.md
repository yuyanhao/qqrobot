# qqrobot 指令及功能汇总

群聊每条操作请先 @ 机器人，私聊可以直接发。有题号的操作请用提交原题的账号，在原会话发送。方括号中的参数可以省略。支持全角斜杠「／」。

## 提交、补材料与核对题干

| 怎么发 | 用法 |
|---|---|
| **直接发数学或物理题的文字、图片** | 创建题号、排队解题。支持 QQ 随引用提供的文字和附件。 |
| **群聊 @ 机器人并附 PDF** | 创建题号、排队解题。可随文件写「只读第3-5页」或「第2、5、8-10页」指定范围。 |
| **私聊先发 PDF，再引用那条消息并写明要求** | 单发普通 PDF 时机器人保持静默。引用时可以写「只读第3-5页，解答例2」。要用指令指定用途时，可发「/查错」「/补图」等并附材料。 |
| **/收集 [说明]** 或 **/收集 原题号 [说明]** | 建立材料收集记录，暂缓解题。可随首条消息上传第一批材料。 |
| **/补图 收集题号 [PDF页码]** | 追加附件，可同条附图或 PDF。要读取特定页时可发「/补图 收集题号 第3-5页」并同条附 PDF。页码随每批 PDF 保存，每条最多 4 个附件，单题合计 12 个。 |
| **/开始 收集题号** | 收齐材料后单独发送，沿用此题号解题。 |
| **/补充 题号 [补充条件]** | 同条附文字或图。收集中的题直接追加，已经开始的题创建关联题。 |
| **/题干 题号 [段号]** | 查看转写和识图备注。 |
| **/确认题干 题号 [更正]** | 核对识图疑点后继续原任务模式，返回新题号。转写正确时只填题号。查询旧题号时会提示继续处理的新题号。 |
| **/追问 题号 [具体问题]** | 用原题和已有解答继续讨论，可配文字或图片。 |

普通 PDF 每份上限为 10 MB，指定页码时也适用。页码从文件第一页数起。同一条消息内的普通 PDF 共用页码范围，省略范围时读取全部页。

## 共享书库

| 怎么发 | 用法 |
|---|---|
| **/书库 [列表页]** 或 **/引用** | 查看连续编号、书名、页数和简介。移除一本后，后续书籍编号自动顺延。点击编号可填入引用指令，再补物理页码。 |
| **/引用 B0001 第3-5页 [解题要求]** | 读取该书指定页并创建新题。页码可放在要求前面、后面或要求句中；写明“第4题”时只识别该题及其小问，例如「/引用 B0001 解决一下第56页的第四题」。机器人可用的群和私聊共用书库。 |
| **/入库 书名 [｜简介]** | 管理员私聊可同条附一份 PDF；也可先单独发送 PDF，收到机器人“已暂存”确认后，在 15 分钟内发送入库命令，无需引用或重发文件。例如「/入库 数学分析上册 ｜ 极限、连续与微分」。简介可省略。 |
| **/移除书籍 B0001** | 管理员在私聊移除指定书籍。当前书库编号保持连续，后续书籍自动顺延；已排队或处理中的任务仍可读取原书，后台在没有待处理引用时删除 PDF。 |

程序对管理员入库的 PDF 不设文件大小上限。QQ 入库以平台实际传送能力和服务器磁盘空间为准。单独发送的 PDF 会先下载到服务器临时暂存，15 分钟后失效；重启服务会清除未完成的暂存文件。书籍存放于数据目录的 books 子目录，可随数据目录备份。部署时将 BOOK_ADMIN_OPENID 设为管理员的 QQ 单聊事件中的 author.user_openid。若启用了 ALLOWED_USERS，管理员也须在白名单中。

也可在云端把书籍传到机器人服务账号能读取的位置，再以该账号运行下列命令。默认 systemd 服务账号是 qqbot，数据目录是 /opt/qq-math-bot/data。

~~~bash
python book_library.py --data-dir /opt/qq-math-bot/data add /path/to/book.pdf '数学分析上册' --summary '极限、连续与微分'
python book_library.py --data-dir /opt/qq-math-bot/data list
python book_library.py --data-dir /opt/qq-math-bot/data remove B0001
~~~

## 查错

查错只依据题面和你提交的推导，回复正确性、完整性及缺失的依据或步骤。

| 怎么发 | 附件如何使用 |
|---|---|
| **/查错 题号 [草稿文字]** | 已有题号时，同条附的图片都作草稿。可一次提交最多 4 个附件，也可以只写草稿文字。 |
| **/查错 [草稿文字]** 并同条附题目和过程 | 第一份附件是题目，后面的附件是过程。例如先附题目图，再附两张草稿图。PDF 也可以作过程附件。 |
| **/查错 [草稿文字]** 并引用原题 | 引用中的文字和附件作题面，这条消息附上的图片和写出的过程作草稿。 |
| **/查错 第3页 [草稿文字]** 并同条附题目 PDF | 从题目 PDF 的物理第 3 页读取题面。可以同时写出过程，也可以在 PDF 后附草稿图。 |
| **/查错 B0001 第3页 [草稿文字]** | 用书库页码作题面，同条附的图片均作草稿，也可以只写过程文字。 |

查错反馈以文字发送，发对应题号可再次领取。题图和草稿请按附件顺序发送。选了题号再附图时，图片放到最终发送的那条消息里。

## 进度、领取与任务管理

| 怎么发 | 用法 |
|---|---|
| **题号** 或 **/结果 题号** | 查询状态，完成后领取。排版后 1–3 页发全部图片，超过 3 页发完整 PDF。若只有文字稿，发回第一段并标明复核情况。 |
| **/结果 题号 第2段** | 按文字稿末尾的提示继续领取其他段落。 |
| **/进度 题号** | 查看进度与复核情况。 |
| **/最近** | 从本会话自己的最近最多 3 个有效题号中选择，列表显示提交时间。已到保留期且处理结束的普通题会在清理前先从列表隐藏。点击只把题号填入输入框。 |
| **/题目** | 查看自己在本会话最近 5 个任务。 |
| **/PDF 题号** | 领取完整 PDF，也接受「/pdf」。 |
| **/图片 题号 [起始页]** | 从指定页起取最多两页，默认从第 1 页起。 |
| **/取消 题号** | 取消收集、排队或运行中的任务。 |
| **/重试 题号** | 用原材料再运行一次，创建新题号，可能产生 API 费用。 |
| **/帮助** | 查看帮助，也接受「/help」和「帮助」。群里只发 @ 也能查看帮助。 |

如果模型公式未通过 XeLaTeX 编译，机器人用转义原文补生成可读 PDF，并在结果里标明。错过自动交付时，可用新消息发题号或指定领取命令。

## 收藏与复习

| 怎么发 | 用法 |
|---|---|
| **/收藏 题号 [错因]** | 可提前收藏，题干读取后和解答完成后自动补入。每人在每个会话最多收藏 100 道，错因最多 300 字。 |
| **/收藏 [列表页]** | 查看自己在当前会话中的收藏。 |
| **/复习 [题号]** | 指定题号时发含题干、答案及错因的 PDF。省略题号时按收藏时间从早到晚列出，点击编号把指令填入输入框。列表可用「/复习 2」翻页。 |
| **/取消收藏 题号** | 从收藏移除，题目随后按普通清理规则处理。 |
| **/错题本** | 将当前会话的本人收藏按收藏时间从早到晚合并为一个 PDF。答案尚在生成的题会标明状态。 |

普通题超过 7 天后清理，删除数据库记录和任务文件。服务启动时清理，运行期间每小时检查一次。收藏题没有到期时间，运行中的任务会等结束后清理。

## 群聊原生指令面板

手机 QQ 可在选中 @ 机器人后显示下列固定入口。若面板未展开，可接着输入「/」。发送「/最近」可选择个人最近题号。在群里发未带题号的「/PDF」或「/进度」等指令，也会收到带题号的备选指令。「/查错」只推荐题干可用的题号。按钮权限不可用时可以复制对应的文字。 [腾讯 QQ 机器人指令面板说明](https://github.com/tencent-connect/bot-docs/blob/main/docs/develop/api-v2/client-func/intro/baseinfo.md#指令面板) · [腾讯 QQ 消息按钮说明](https://github.com/tencent-connect/bot-docs/blob/main/docs/develop/api-v2/server-inter/message/trans/msg-btn.md)

| 面板指令 | 显示说明 |
|---|---|
| /帮助 | 查看全部指令和用法 |
| /查错 | 检查推导是否正确和完整 |
| /最近 | 选择自己的最近三个题号 |
| /题目 | 查看自己最近提交的题目 |
| /进度 | 输入题号查询处理进度 |
| /结果 | 输入题号领取解题结果 |
| /PDF | 输入题号领取完整PDF |
| /题干 | 输入题号查看题干和疑点 |
| /确认题干 | 确认题干或填写更正 |
| /追问 | 输入题号和想追问的问题 |
| /收集 | 分批提交同一道题的材料 |
| /补图 | 为收集中的题目追加材料 |
| /开始 | 收齐材料后开始解题 |
| /收藏 | 查看收藏或输入题号保存 |
| /复习 | 选收藏并领取题目和答案 |
| /错题本 | 把本会话的收藏导出为PDF |
| /书库 | 查看共享的PDF书籍 |
| /引用 | 按书籍编号和页码解题 |

### 发布方式

更新部署后，在装有依赖的源码目录运行下面的命令。第一条在本地预览配置，第二条使用部署目录的 QQ 配置同步。这是全局群聊面板，适用于这台机器人可用的群。发出指令后，仍按机器人现有的白名单和题号权限处理。若 QQ 已有其他全局群指令面板，脚本会提示核对。 [QQ 群聊指令面板接口](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/menu-panel/)

~~~bash
python qq_panel.py
python qq_panel.py --apply
~~~

默认 systemd 安装可在云端执行「sudo -u qqbot /opt/qq-math-bot/.venv/bin/python /opt/qq-math-bot/qq_panel.py --apply」。Docker 部署可执行「docker compose exec qqbot python qq_panel.py --apply」。成功后在手机 QQ 的机器人所在群点选 @ 机器人，并用「/帮助」做一次收发验证。

也可在 [QQ 开放平台](https://q.qq.com/) 选择对应机器人。若管理端提供「发布配置 → 功能配置 → 指令配置」，可按上表填写指令名和简介，场景选「QQ群」，并按页面提示保存或提交。若页面自动添加「/」，指令名栏只填斜杠后的名称。 [腾讯机器人发布配置说明](https://github.com/tencent-connect/bot-docs/blob/main/docs/README.md#912-指令配置)
