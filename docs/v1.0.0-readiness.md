## 发布动作

1. 推送 `release: v1.0.0` 提交并等待 push/PR 两条 CI 全绿。
2. PR #1 转 ready，使用 squash 合并到 `main`（满足线性历史）。
3. `Publish version` 工作流等待 `release` environment 审阅；批准后创建 `v1.0.0`。
4. 检查 Release：只含 v1.0.0 说明、标记 Latest、标签指向 main 合并提交。
5. 按 `docs/upgrading.md` 在云端升级；保留 `.env` 与 `data/`，部署后做 QQ 冒烟。
