# 升级指南

## 从 v0.2.6 升级到 v1.0.0

先按[备份指南](backup.md)停止服务并备份 `.env` 与整个 `data` 目录。升级会保留 SQLite 任务记录、收藏、附件和共享书库；应用启动时按需迁移数据库结构。

v1.0.0 更改了 PDF 输入规则：每份要读取的 PDF（题面、书库引用、草稿、补充/追问和附加材料）都必须明确写出物理页码；单份 PDF 和整项任务合计最多 5 页。`PDF_INPUT_MAX_PAGES`、`PDF_TASK_MAX_PAGES` 可在 1–5 之间调低，不能调高。没有明确页码的旧任务在重试时会被拒绝；请改为例如 `/引用 B0001 第3-5页` 或在附件说明里写「只读第3-5页」。管理员书库入库只保存 PDF，不读取页面，不需要选页。

升级程序：

1. 确认备份文件可读，并记录正在运行的版本和服务方式。
2. 停止服务，在新代码目录运行 `sudo bash setup.sh`，或按 README 的 Docker Compose 步骤重建容器。
3. 检查离线配置、服务状态与日志。
4. 在 QQ 私聊和群聊分别验证发文字题、图片题、指定 PDF 页、查询、追问、取消和结果领取。
5. 至少保留升级前归档，确认新版本稳定后再按组织的保留周期清理。

## 回滚

停止新服务，恢复与旧代码相匹配的配置和完整数据备份，再部署备份时对应的代码版本。不要只回滚程序文件并继续使用尚未备份或结构已改变的数据库。
