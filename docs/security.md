# 资源边界与威胁模型

本项目把 QQ 消息和附件视为不可信输入。服务在本地下载、解析和渲染材料，模型推理则发送到所配置的远端 API。部署者应告知使用者题目、草稿和附件会被发送给模型服务商，并遵守相应的隐私与数据保留要求。

## 当前资源边界

- 普通 PDF：每个文件最多 10 MB；题目 PDF 必须明确指定物理页码；单份默认最多 10 页、单任务默认合计最多 20 页（`PDF_INPUT_MAX_PAGES` / `PDF_TASK_MAX_PAGES`）。非题目 PDF 未写页码时自动读取前 5 页。
- 书库 PDF：每份默认最多 100 MB，已存 PDF 总量默认最多 1 GB（`BOOK_MAX_PDF_MB` / `BOOK_LIBRARY_MAX_MB`）；下载时限 30 分钟，并保留至少 64 MB 磁盘空间。
- 图片渲染限制页面像素、边长和 PNG 体积；PDF 通过可终止的渲染子进程分批处理。
- 任务队列、用户配额、附件数量、结果保留期与数据目录容量均有限制。
- TeX 使用安全数学命令白名单；表达式计算和排版在子进程中运行。

这些限制降低意外高成本、资源耗尽和输入滥用的风险，不构成对任意恶意文件的安全保证。只向可信用户开放机器人；为 API 设置服务商侧预算和速率限制；使用非 root 账户、受限目录和操作系统资源限制；定期更新依赖并保护备份。

不要公开 `.env`、QQ OpenID、题目原图、模型请求或包含用户内容的日志。报告漏洞请按 [SECURITY.md](../SECURITY.md) 私下联系维护者。
